# 📈 Crypto Tracker

> Автоматический сбор курсов **BTC** и **TON (Gram)** каждые 5 минут с кросс-проверкой из трёх бирж, средним значением и готовым анализом для стратегии.

## 🚀 Что это

Скрипт раз в 5 минут опрашивает **три независимых источника**, пишет средние значения в CSV и хранит историю для последующего анализа рыночной стратегии.

**Источники (все без API-ключа):**

| Биржа | BTC | TON | Почему |
|-------|-----|-----|--------|
| [Kraken](https://www.kraken.com) | ✅ | ✅ | Основной — актуальные котировки |
| [Coinbase](https://www.coinbase.com) | ✅ | ✅ | Альтернатива, TON ≈ 1.40 |
| [Bitfinex](https://www.bitfinex.com) | ✅ | ✅ | Альтернатива, TON ≈ 1.40 |

> ⚠️ Binance по TON даёт завышенные значения (~1.60 против ~1.40 на Kraken/Coinbase/Bitfinex) — поэтому исключён из среднего и используется только как справочный.

## 🔧 Установка и запуск

```bash
# 1. Скрипт сбора (ручной запуск — для проверки)
python3 fetch_prices.py
# → [2026-09-07T17:07:34Z] BTC avg=$79,111.65 (3 ист.)  TON avg=$1.4026

# 2. Автозапуск каждые 5 минут через cron
crontab -e
# добавить строку:
*/5 * * * * /usr/bin/python3 /root/ai/crypto-tracker/fetch_prices.py >> /root/ai/crypto-tracker/data/cron.log 2>&1
```

## 📊 Формат данных (`data/prices.csv`)

| Колонка | Описание |
|---------|----------|
| `ts` | Время (UTC, ISO-8601) |
| `btc_kraken`, `btc_coinbase`, `btc_bitfinex` | BTC от каждой биржи |
| `btc_avg` | **Среднее BTC** — основной показатель для анализа |
| `ton_kraken`, `ton_coinbase`, `ton_bitfinex` | TON от каждой биржи |
| `ton_avg` | **Среднее TON** — основной показатель |
| `btc_ton_ratio_avg` | Соотношение BTC/TON (среднее) |

> **Правило анализа:** ориентируемся на `*_avg` (среднее по доступным источникам) — оно сглаживает расхождения бирж.

## 📈 Анализ

```bash
python3 analyze.py            # статистика за весь период
python3 analyze.py 24         # последние 24 часа
python3 analyze.py 24 --json  # отчёт в JSON (для машины/ИИ)
```

Вывод: период, первое/последнее значение, min/max/mean, изменение в % — по BTC, TON и BTC/TON.

## 📈 Торговые сигналы (`signals.py`)

Считает технические индикаторы по средним значениям и выдаёт рекомендации **BUY / SELL / HOLD**, плюс общий вердикт голосованием.

```bash
python3 signals.py            # все сигналы за весь период
python3 signals.py 24         # за последние 24 часа
python3 signals.py 24 --json  # JSON (для машины/ИИ)
```

### Стратегии и индикаторы

| Индикатор | Сигнал | Идея |
|-----------|--------|------|
| **MA (скользящие средние)** | быстрая MA(20) > медленной MA(50) → `BUY`, иначе `SELL` | тренд: «золотой» / «смертельный» крест |
| **RSI(14)** | `< 30` → `BUY`, `> 70` → `SELL` | перепроданность / перекупленность |
| **Z-score** | `≤ -2` → `BUY`, `≥ +2` → `SELL` | mean reversion: отскок к среднему |
| **Ротация BTC/TON** | MA fast/slow по `btc_ton_ratio_avg` → `BUY_TON` / `BUY_BTC` | перекладывание между активами |
| **Спред бирж** | расхождение Kraken/Coinbase/Bitfinex | маркер рыночной «нервозности» |

**Общий вердикт** — голосование простым большинством по всем BUY/SELL-сигналам.

⚠️ Для первых сигналов нужно **≥20 записей** (MA и z-score) и **≥15** (RSI).
Данные копятся каждые 5 минут, так что полноценные сигналы появятся через ~2 часа
после начала сбора.

## 🧠 Для стратегии

Накопленная база (`prices.csv`) позволяет:
- трекинг трендов (скользящие средние, моментум),
- волатильность (min/max, разброс по биржам),
- расхождение BTC/TON (арбитраж-сигналы),
- корреляция с 24h-изменениями (когда источники начинают расходиться).
